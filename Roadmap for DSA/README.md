## 📍 How to Use This Roadmap

1. **Follow the order** — Start from basics and move to advanced topics
2. **Learn → Practice → Revise** — For each topic, understand theory, solve problems, and revise weekly
3. **Track progress** — Mark ✅ when you complete a topic
4. **Consistency > Speed** — 2-3 hours daily is better than 10 hours once a week

## 📊 Phase 5: Problem-Solving Strategy

### ✅ How to Approach Any Problem

1. **Read Carefully** — Understand input, output, constraints
2. **Identify Pattern** — Which DSA pattern fits?
3. **Brute Force First** — Write naive solution
4. **Optimize** — Reduce time/space complexity
5. **Edge Cases** — Test with edge inputs
6. **Dry Run** — Trace through code manually

### ✅ Common Triggers for Each Pattern

| If you see... | Think of... |
|---------------|-------------|
| Sorted array + search | Binary Search |
| Contiguous subarray/substring | Sliding Window / Prefix Sum |
| Pair/triplet with target sum | Two Pointers / Hashing |
| All combinations/permutations | Backtracking |
| Min/Max optimal value | DP / Greedy |
| Shortest path in unweighted graph | BFS |
| Shortest path in weighted graph | Dijkstra |
| Dependencies/prerequisites | Topological Sort |
| Next greater/smaller element | Monotonic Stack |
| Kth largest/smallest | Heap |
| Connected components | DFS / Union Find |
| String matching | Trie / KMP |
| Range queries | Segment Tree / Fenwick Tree |
